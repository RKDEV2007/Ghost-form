ПЛАН ПРЕЗЕНТАЦИИ — «GHOST FORM STAGE»
Игра-симулятор по веб-безопасности
======================================

Итого: 8 слайдов | ~7 минут выступления | 3 докладчика


----------------------------------------------------------------------
СЛАЙД 1 — ТИТУЛЬНЫЙ
----------------------------------------------------------------------

Содержимое:
  • Название: Ghost Form Stage
  • Подзаголовок: браузерная игра по основам веб-безопасности
  • Скриншот — стартовый экран игры
  • Авторы, дата, группа

----------------------------------------------------------------------
СЛАЙД 2 — ЧТО МЫ ДЕЛАЛИ И ЗАЧЕМ
----------------------------------------------------------------------

Проблема:
  Разработчики знают про CSRF и XSS из учебников, но
  никогда не «трогали» атаку руками.

Наше решение:
  Игра, в которой игрок сам находит уязвимость и чинит её.
  Не читает — делает.

Целевая аудитория: студенты IT-специальностей, начинающие разработчики.

----------------------------------------------------------------------
СЛАЙД 3 — КАК УСТРОЕНА ИГРА
----------------------------------------------------------------------

Структура:
  5 игровых дней = 5 тем по безопасности:

  День 1 — CSRF-токены
  День 2 — сессии и куки
  День 3 — проверка Origin / SameSite
  День 4 — DOM-инъекции
  День 5 — финальный выбор стратегии (3 концовки)

Персонаж Хлоя ведёт игрока через сюжет и объясняет,
что происходит на «сервере».

Скриншоты: DialogueBox + SERVER LOG с Ghost POST

----------------------------------------------------------------------
СЛАЙД 4 — ИНТЕРФЕЙС
----------------------------------------------------------------------

Аннотированный скриншот GameScreen:

  ЛОГИ    — серверные запросы, здесь видно атаку
  INSPECT — редактор HTML/JS кода, здесь чинят уязвимость
  ФОРМА   — отправка запроса, проверка результата

  Справа — список задач (Missions)
  Вверху — статы: жизни, концентрация, уровень безопасности

----------------------------------------------------------------------
СЛАЙД 5 — ТУТОРИАЛ
----------------------------------------------------------------------

Что сделали:
  Полноэкранный обучающий экран при первом запуске игры.

Из чего состоит:
  1. Карточка с Хлоей — объясняет 5 разделов интерфейса
  2. Интерактивный гид (4 шага):
       Шаг 1 → открой ЛОГИ         (видишь запросы)
       Шаг 2 → открой INSPECT      (видишь редактор)
       Шаг 3 → открой ФОРМУ        (видишь поля)
       Шаг 4 → напиши <input> в    (первое задание
                редакторе кода      в коде)

  После этого — начинается первый день.

Источник требований: техническое задание (тз2.docx)

----------------------------------------------------------------------
СЛАЙД 6 — СТЕК И АРХИТЕКТУРА
----------------------------------------------------------------------

  Frontend:   React 19 + Vite 8
  Стили:      чистый CSS, шрифт JetBrains Mono
  Состояние:  useReducer + Context API (без Redux)
  Backend:    Express 5, REST API сохранений
  Хранение:   localStorage + JSON-файл на сервере

Что интересного в коде:
  • Гайд-система на событиях — каждый шаг срабатывает
    по конкретному действию игрока (completeOn pattern)
  • Merge-стратегия сохранений — побеждает более свежий
    timestamp (можно играть с двух устройств)
  • Таймер концентрации — давление на игрока каждые 12 сек
